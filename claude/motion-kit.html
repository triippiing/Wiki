01 What it is
01 Three skills, one idea: every frame is a function of time OVERVIEW ▶

Motion Kit is three Claude Code skills that turn a project's UI into motion, all in code. motion-design plans a promo and stops for approval. motion-video builds it as one HTML page whose seek(t) draws any frame from the time alone, then renders that page to MP4 with Playwright and ffmpeg, cut to a song's measured beat grid. motion-ui brings the same closed-form springs into a real product UI. There is no After Effects, Remotion or Lottie in the chain.

The look and the build rules adapt the open prompt template from @twoclipping: one shape that never cuts, a cursor that drives every change, springs everywhere, and a last frame identical to the first so the clip loops.

Demos 1 and 2 keep the Tints audio. It is a commercial track, so these are for viewing here. Re-time to a licensed track (see step 05) before posting them anywhere else.

03 Install
03 Link the skills, then run the doctor SETUP ▶
~/motion-kit/install.sh ~/.claude/skills/motion-video/scripts/doctor.sh

install.sh symlinks each folder in ~/motion-kit/skills/ into ~/.claude/skills/ (it refuses to replace a real folder of the same name), runs npm install for Playwright, then runs the doctor. The doctor lists anything MISSING with the fix.

Prerequisites: Homebrew, ffmpeg (brew install ffmpeg), Node and Python 3. The scripts put /opt/homebrew/bin on their own PATH, so they work even when Claude's shell has not.

05 Pipeline
05 From a song to a rendered loop PIPELINE ▶

The order is fixed: song, then song.json, then a state table, then the approval gate, then the seek(t) page, then beat stills, then the render. Nothing is coded until the table is approved.

  1. analyze_song.py measures BPM and the beat grid and writes song.json and clip.wav.
  2. Claude writes one row per beat: something happens on every beat, and the last row returns to the first state.
  3. You approve or change the table.
  4. Claude edits only the tables in index.html: states(), cursor(), content, extraSfx().
  5. beat_stills.mjs writes one still per beat, a contact sheet and a loop-seam check. Read the sheet before rendering.
  6. render.mjs renders 60 fps, 4 subframes per frame, to out/video.mp4.
ScriptFlagsJob

--from and --to are seconds and render a section. --serve prints a URL: open it with ?play and click to watch with audio.

06 Any project
06 Re-theme and re-size to fit the project THEME ▶

extract_theme.py reads the first :root block of a stylesheet (the light theme) plus the body or html font-family, and writes theme.css and theme.json into the project. Colours are normalised to #rrggbb so springs can interpolate them. Without a CSS file it writes the house theme: warm gray, black and white, Geist.

RoleFound from these variables
canvas--bg, --background, --canvas, --color-bg, --bg-color, --page
surface--panel, --surface, --card, --paper, --bg-elevated, --color-surface
ink--ink, --text, --fg, --foreground, --color-text, --text-color
muted--muted, --text-muted, --subtle, --color-muted
accent--accent, --primary, --brand, --color-primary, --color-accent
font--font, --font-sans, --font-family, --font-body, or the body font
pos, neg (optional)Success and danger colours, included only when the CSS defines them

When a role is picked wrongly, override it and check the printed theme:

python3 $S/extract_theme.py app/style.css --out ~/promo --map accent=--brand

Pages then use the roles (canvas surface ink muted accent) or var(--accent), never a hex value, so the piece re-themes with the project. Use var(--pos) and var(--neg) only when the theme has them.

Sizes. --size square is 1440x1440 (the default), vertical is 1080x1920 for Reels, TikTok and Shorts, landscape is 1920x1080, or pass WxH with even numbers of at least 64.

07 Song rules
07 What song.json tells you RULES ▶
  • Comfort band. 100 to 130 BPM. Outside it the analysis warns: below, keep one event per beat; above, consider half-time events or half-beat accents. Say the BPM and any warning out loud before planning.
  • House spring. rules.spring sets zeta 0.85 and a settle of 0.6 beat (0.33 s at 109 BPM). The template already uses it. Camera and cursor use zeta 1.
  • Hold time. rules.min_hold_beats is the fewest beats a state may hold, from one second of screen time (2 beats at 109 BPM). rules.max_states follows from it (14 for a 7-bar loop).
  • Cue placement. Every sound sits on its beat's measured cue_t, not the grid time. Presses use sfx/click.wav, typing uses sfx/key.wav, anything else goes through extraSfx(). Put the biggest changes on the strongest per-beat accent values.
  • Loop start. Choose --start-bar at a section boundary inside a strong section, and use a different bar for each piece made from one song. Demo 1 starts at bar 21, demo 2 at bar 7.
  • Licence. A commercial track is for local viewing. Ask for a file and never download music.
08 In-app motion
08 The project's motion spec wins MOTION-UI ▶

Before proposing anything, motion-ui looks for the project's motion rules and treats them as the spec: docs folders named motion, animation or handoff, CSS tokens such as --t-*, --dur-* and --ease-*, and existing transition:, @keyframes and reduced-motion handling. If the spec bans bounce, every spring is zeta 1, and durations come from the tokens through Springs.fromSettle(tokenSeconds, zeta).

The worked example is demo 3. The dock indicator used to slide on a CSS transform transition. It now rides two edges, each on its own critically damped spring (zeta 1). The edge on the side it is heading toward settles in 0.7 of --t-travel (220 ms) and the trailing edge takes the full time, so the pill reaches ahead and gathers up behind. Each edge keeps its position and velocity between navigations and is held between where it was and where it is going, so a quick reversal cannot pass its target. Reduced motion and a missing requestAnimationFrame make the pill jump.

// hand copy from ~/motion-kit, may drift const trail = Springs.fromSettle(settle, 1), fast = Springs.fromSettle(settle * 0.7, 1);

The branch motion-demo in the finance app is unmerged and unpushed, and main is untouched. Its tests pin the behaviour: settles on target, never overshoots, retargets stay continuous, and the pill never collapses or leaves the dock.

09 Troubleshooting
09 Common failures FIXES ▶
SymptomCause and fix
Seam check fails on frameThe last STATES and CURSOR rows must equal the first and sit at least 2 beats before the end.
Seam check fails on cursor velocityThe last cursor move is too late. Finish it earlier so the cursor is at rest across the seam.
Blurry textSomething the camera scales has will-change. Remove it.
Page renders unstyledIt was opened from file://. Use render.mjs DIR --serve.
Labels overlap in a morphing boxGive swapping text its own exit and enter timing.
ffmpeg or node not foundClaude's shell PATH lacks Homebrew. The scripts add it themselves, so run them through the scripts, and run the doctor.
